# Деплой: GitHub + Timeweb

Инструкция по публикации исходников на GitHub и размещению статической сборки
на поддомене 3-го уровня в Timeweb с бесплатным SSL-сертификатом Let's Encrypt.

Сборка получается полностью статической (папка `dist/`), поэтому Node.js на
сервере не требуется — достаточно обычного виртуального хостинга.

---

## Шаг А. Публикация исходного кода на GitHub

```bash
# 1. Инициализировать git-репозиторий
git init

# 2. Добавить все файлы (node_modules и dist уже в .gitignore)
git add .

# 3. Первый коммит
git commit -m "Initial commit: To-Do app (Vite + React)"

# 4. Создать пустой репозиторий на github.com и привязать его
git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git

# 5. Отправить код
git branch -M main
git push -u origin main
```

## Шаг Б. Сборка и публикация на Timeweb

### Б.1. Собрать проект

```bash
npm install
npm run build
```

После выполнения появится папка `dist/`, содержащая `index.html` и `assets/`.
Важно: в `vite.config.js` задан `base: './'`, поэтому все пути к скриптам и
стилям относительные и корректно резолвятся на поддомене 3-го уровня.

### Б.2. Создать поддомен 3-го уровня в Timeweb

1. Войти в панель: https://hosting.timeweb.ru
2. Открыть раздел **«Домены и SSL»** → **«Поддомены»**.
3. Выбрать домен (`24di.online`), указать имя поддомена `todo`.
4. Указать корневую директорию сайта (например, `todo/public_html`)
   и нажать **«Создать»**.

### Б.3. Выпустить SSL-сертификат Let's Encrypt

1. В разделе **«Домены и SSL»** выбрать созданный поддомен `todo.24di.online`.
2. Нажать **«Выпустить SSL-сертификат»** (тип — бесплатный Let's Encrypt).
3. Дождаться активации и убедиться, что сайт доступен по `https://`.

### Б.4. Загрузить содержимое папки dist/ в public_html

1. Открыть **«Файловый менеджер»**.
2. Перейти в корневую директорию поддомена (`todo/public_html`).
3. Загрузить **содержимое** папки `dist/` (файл `index.html` и папку `assets/`),
   не саму папку `dist/`.

Либо через FTP/SFTP (данные доступа указаны на дашборде панели):

```
Хост: vh454.timeweb.ru
Логин: cw242295
```

4. Удалить из директории файлы-заглушки (`index.php`, `index.html` по умолчанию),
   если они мешают открытию приложения.

### Б.5. Проверка

Открыть `https://todo.24di.online` — приложение должно загрузиться, стили и
скрипты подключиться без ошибок 404, а в адресной строке — валидный HTTPS.

## Шаг В. Бэкенд: PHP + MySQL

Фронтенд обращается к `/api/...`, поэтому на том же хостинге нужен PHP + MySQL.

### В.1. Создать базу

В панели Timeweb → **«Базы данных»** создать БД MySQL (напр. `cw242295_todo`).
Логин пользователя БД на Timeweb совпадает с именем БД. Записать хост/имя/логин/пароль.

### В.2. Креды и файлы бэкенда

1. `server/todo/config.example.php` → скопировать в `config.php`, заполнить креды.
2. Загрузить по FTP/SFTP:
   - `config.php`, `db.php` → в `~/todo/` **вне** web-корня;
   - содержимое `server/todo/public_html/` (`.htaccess`, `api/index.php`, `setup.php`)
     → в `~/todo/public_html/`;
   - содержимое `dist/` (фронтенд) → в `~/todo/public_html/`.

### В.3. Инициализация таблиц

Открыть `https://todo.24di.online/setup.php` один раз (создаст `lists` и `todos`),
затем **удалить** `setup.php` с сервера.

### В.4. Проверка API

```bash
curl https://todo.24di.online/api/lists
# → {"ok":true,"lists":[{"id":1,"name":"Входящие",...}]}
```
