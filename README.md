# To-Do — брутальный полноценный таск-менеджер

Фулстек To-Do приложение: **React 19 + Vite** на фронте, **PHP 8 + MySQL** на бэкенде.
Несколько списков, приоритеты, сроки, теги, поиск, drag-and-drop и перетаскивание
с сохранением порядка — всё хранится в базе и доступно с любого устройства.

Живое демо: **[https://todo.24di.online](https://todo.24di.online)**

## Возможности

- Несколько списков: создание, переименование, удаление, переключение.
- Задачи: добавление (с приоритетом, сроком и тегами), редактирование, выполнение, удаление.
- Приоритеты (нет / низкий / средний / высокий) с цветовой индикацией.
- Сроки с подсветкой просроченных задач.
- Теги: чипы на задаче и фильтр по тегам.
- Поиск по тексту и тегам.
- Фильтры с счётчиками: все / активные / выполненные.
- Drag-and-drop сортировка (мышь и клавиатура), порядок сохраняется в БД.
- Очистка выполненных задач.
- Брутальный адаптивный дизайн (тёмная тема, `prefers-reduced-motion`).

## Стек

**Фронтенд**
- [React 19](https://react.dev/), [Vite 6](https://vite.dev/)
- [@dnd-kit](https://dndkit.com/) — drag-and-drop
- Чистый CSS (переменные-токены, брутальный стиль)

**Бэкенд**
- PHP 8.2 (PDO, prepared statements)
- MySQL / MariaDB
- REST API `/api/...` на одном фронт-контроллере

## Локальный запуск

Нужен [Node.js](https://nodejs.org/) 18+.

```bash
npm install
npm run dev      # dev-сервер
npm run build    # сборка в dist/
npm run preview  # локальный просмотр сборки
```

Для работы с API локально нужен бэкенд (PHP + MySQL) по адресу `/api`;
на проде он живёт на том же домене.

## Бэкенд

1. Создайте БД MySQL и пользователя.
2. Скопируйте `server/todo/config.example.php` → `config.php` **вне web-корня** и заполните креды.
3. Загрузите `db.php` и `config.php` в корень приложения (на хостинге — `~/todo/`), а содержимое
   `public_html/` — в web-корень (`~/todo/public_html/`).
4. Откройте `setup.php` один раз для создания таблиц, затем **удалите** его.
5. `.htaccess` обеспечивает редирект HTTP→HTTPS и роутинг `/api`.

Подробнее — в [DEPLOY.md](DEPLOY.md).

### API (кратко)

| Метод | Путь | Действие |
|---|---|---|
| GET | `/api/lists` | списки со счётчиками |
| POST | `/api/lists` | создать список |
| PATCH/DELETE | `/api/lists/{id}` | переименовать / удалить |
| GET/POST | `/api/lists/{id}/todos` | задачи списка / создать задачу |
| PATCH/DELETE | `/api/todos/{id}` | обновить / удалить задачу |
| POST | `/api/todos/reorder` | порядок задач |
| POST | `/api/todos/clear-completed` | удалить выполненные |
